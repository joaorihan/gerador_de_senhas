# Gerador de Senhas Seguras

Um gerador de senhas personalizável desenvolvido em Python com interface gráfica usando Tkinter.

## Funcionalidades

- Geração de senhas aleatórias
- Personalização do tamanho da senha
- Opção de incluir letras, números e caracteres especiais
- Botão para copiar a senha automaticamente

## Pré-requisitos

- Python 3.x
- pip

## Instalação

1. Clone este repositório
2. Instale as dependências:
```bash
pip install -r requirements.txt
```

## Como Usar

Execute o programa com:
```bash
python main.py
```

## Tecnologias Utilizadas

- Python
- Tkinter
- Pyperclip
